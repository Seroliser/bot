Privacy policy

Juan is a personal assistant used only by its owner. It is not a public service and has no other users.

What data it accesses

With the owner's permission, Juan reads and updates the owner's Google Calendar events so it can answer questions about the schedule and create or move events when asked.

How data is handled

  • Calendar data is processed on the owner's own server by a locally running AI model.
  • It is not sold, shared with third parties, or used for advertising or training.
  • The Google access token is stored only on the owner's server.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
